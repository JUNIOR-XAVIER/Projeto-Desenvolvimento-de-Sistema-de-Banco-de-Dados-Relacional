Projeto de Banco de Dados Relacional - Supermercado

Este projeto foi desenvolvido como parte do curso de Tecnologia em Banco de Dados da PUC Minas.  
O objetivo é projetar e implementar um sistema de banco de dados relacional para o setor supermercadista.

Objetivos
- Cadastro de clientes, fornecedores e funcionários
- Controle de estoque e produtos
- Registro de vendas e itens de venda
- Relatórios estratégicos para a gerência

Tecnologias utilizadas
- MySQL Workbench
- Draw.io
- Google Colab + Pandas

Estrutura
- `sql/` → scripts de criação e inserção
- `diagramas/` → modelos conceitual, lógico e EER
- `notebooks/` → consultas e validações em Python
- `docs/Projeto.pdf` → documentação completa

Como executar
1. Importe os scripts SQL no MySQL.
2. Utilize os notebooks para rodar consultas e validar resultados.
3. Explore as views criadas para relatórios.
